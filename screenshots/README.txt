Add your application screenshots to this folder, for example:

  1-chat-interface.png      -> Main chatbot UI with sidebar
  2-prediction-result.png   -> Example of a disease prediction with confidence score
  3-eda-wordcloud.png       -> Word cloud output from notebooks/EDA.ipynb
  4-model-comparison.png    -> Model comparison table/console output from train.py

To capture these:
  1. Run `streamlit run app.py`
  2. Interact with the chatbot in your browser
  3. Take screenshots (Win + Shift + S on Windows, Cmd + Shift + 4 on Mac)
  4. Save them in this folder using the names above
  5. Reference them in README.md under the "Screenshots" section
